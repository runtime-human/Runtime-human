# Release milestones

## Internal Prototype

- запускается Tauri shell;
- создаётся/загружается тестовый сейв;
- core deterministic tests проходят;
- без installer/updater обещаний.

## Vertical Slice 0.1

- январь 1990;
- создание персонажа;
- первый MonthRun;
- blocking event suspend/resume;
- save/load/restart;
- basic UI/accessibility;
- private artifact.

## Alpha

- образование и ранняя карьера;
- несколько лет gameplay;
- migrations/backups/Safe Mode;
- balance reports;
- private GitHub Release;
- known limitations documented.

## Beta

- основные карьерные пути;
- projects/open source/life systems;
- content volume sufficient for repeated play;
- signed NSIS candidate;
- updater test channel;
- old-save update matrix;
- external playtesting.

## Release Candidate

- feature freeze;
- full migration corpus;
- Windows VM install/update/uninstall;
- desktop E2E;
- performance/accessibility gates;
- third-party notices/SBOM;
- signing and recovery drill;
- no P0/P1 findings.

## Free Public Release 1.0

- signed installer;
- stable update channel;
- published checksums/changelog;
- backup before update;
- support/bug report instructions;
- privacy statement: no hidden telemetry;
- complete current documentation snapshot.

## Post-release

- patch releases preserve save compatibility;
- feature changes update rules/content versions;
- major migration tested against all supported fixtures;
- mod API remains experimental until explicitly versioned 1.0.

## Не являются release gates baseline

- Steam;
- EU stores/CRA commercial profile;
- payments;
- accounts/backend;
- cloud saves;
- multiplayer;
- second city/country.
