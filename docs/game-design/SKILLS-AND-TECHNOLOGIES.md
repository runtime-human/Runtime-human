# Навыки и технологии

## Разделение понятий

- **Навык** — переносимая способность: debugging, testing, architecture, mentoring.
- **Технология** — конкретный инструмент: C#, Python, React, PostgreSQL.
- **Специализация** — профиль практики: Backend, Frontend, DevOps, AI.
- **Характеристика** — широкая медленно меняющаяся база.

Docker не является языком, а C# не является специализацией. Контент и UI обязаны сохранять эти категории.

## Группы навыков

### Разработка

Programming, Debugging, Testing, Architecture, Performance, Security.

### Производственная работа

Requirements, Planning, Code Review, Legacy Work, Automation, Incident Handling.

### Карьера

Interviews, Negotiation, Mentoring, Leadership, Technical Leadership, Project Management.

### Публичность

Public Speaking, Technical Writing, Content Creation, Networking, Personal Brand.

### Open source

Maintenance, Documentation, Community, Contribution Review, Release Management, Governance, Funding.

### Предпринимательство

Product Discovery, Marketing, Sales, Finance, Hiring, Delegation, Investor Relations.

## Представление прогресса

Авторитетно хранится целочисленный XP. UI отображает уровни 0–10 и прогресс внутри уровня. Формула уровня versioned и тестируется golden fixtures.

## Technology definition

Технология содержит:

- category;
- prerequisites;
- historical lifecycle;
- hardware/platform requirements;
- learning curve;
- transfer groups;
- market demand by era;
- compatible project kinds;
- obsolescence profile.

## Transfer learning

Опыт переносится через явно заданные группы, а не по строковой похожести названий. Например, знание C-подобных языков даёт ограниченный стартовый бонус, но не заменяет реальную практику.

## Историческая доступность

Создание технологии, публичный релиз, локальная доступность, массовость и вакансии моделируются раздельно. Игрок не получает технологию только потому, что она уже существовала в исследовательской среде.

## Баланс

- Новая технология не всегда лучше старой.
- Legacy-навыки сохраняют ценность в соответствующих компаниях.
- Hype создаёт вакансии и риск переоценки.
- End-of-support повышает стоимость поддержки и риски безопасности.
- Игрок может специализироваться глубоко или развивать широкий профиль.
